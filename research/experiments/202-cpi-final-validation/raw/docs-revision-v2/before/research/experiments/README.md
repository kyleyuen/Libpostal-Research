**[202 — accepted CPI final validation](202-cpi-final-validation/README.md),
2026-10-10:** complete for the declared 14-dataset set (130,341 inputs).
Accepted packaged CPI matched original 000 byte-for-byte; all 84 timing
captures passed and exceeded the 10-second parse floor. The geometric mean of
per-dataset median paired-round speedups is 5.806217× unweighted and 5.893289×
with equal geometric weighting of the three source groups. Global maximum peak

58,982,640 B higher. Steady/thread checks are representative-corpus samples;
CPI setup takes about 11.7 s versus 2.8–2.9 s for original. The 4M-case fuzz
evidence compares digest/status streams, not serialized output bytes; the
accepted-CPI exact serializer fuzz was not run. The prior 78-case API evidence
is an archive-linked adaptation. See the [final report](202-cpi-final-validation/FINAL_VALIDATION_REPORT.md)
and [experiment record](202-cpi-final-validation/README.md).
