## Correctness and thread gates

The correctness run is `research/suite/results/203-stream-output-v1/` with config `raw/stream-validation-v1/config.json`. All 14 candidate serialized outputs matched their cached original counterparts byte-for-byte: 130,341 input/output rows total. A one-byte negative control detected the injected mutation. Candidate logs for all 14 dumps and both fuzz seeds confirmed the stream path was active.

The comparisons used cached original outputs. For unseen-v14, the cached original was generated by the fresh original-baseline run recorded in experiment 202; the 203 v14 run did not create another original output dump. Two digest/status checks, seeds 1 and 2, each covered 2,000,000 inputs and matched the preserved original references. Original fuzz was not rerun in 203.

Thread captures are in `raw/stream-steady-thread-v1/thread-captures/`. Six captures total cover golden-v1, OSM v3, and unseen-v14, with one baseline and one candidate capture per corpus. Each capture had six live `ps -M` samples after at least pass 50; all 36 samples reported exactly one OS thread. The candidate capture for each corpus logged `PC_COMPRESS_STREAM active=1`. Every thread process was intentionally SIGKILLed after its sixth valid sample (return code −9); this is distinct from timing runs, which all exited zero. The harness records each sample, PID, command, TSV and binary hashes, gate result, and termination reason in `results.json`.

## Timings

All timing cohorts were serial, gated on AC/LPM/thermal state, and used three rotated rounds. Parsing-only duration is computed from per-pass `us_per_addr × row_count` and excludes setup. Every capture exceeded the 10-second minimum. All 84 timing commands exited 0, and all 42 candidate commands logged the active streaming marker.

## Decision and limits

The strengthened experiment-203 default-parser gates pass: byte-identical cached-output comparisons on the 14 measured corpora; single-threaded parsing in timing and six sampled live-thread captures; and no per-pair peak RSS, peak physical footprint, or representative steady-footprint regression. The candidate was promoted to `research/final/203-cpi-memory` after independent review.

This result does not claim complete public-API compatibility beyond the measured default parser/output interface. The prior 78-call API evidence belongs to 119, not a fresh 203 API run; the known save-after-load limitation under `EXP_PC_COMPRESS` predates 203 and remains. No all-platform build or non-macOS performance validation was run. Model files and PGO/mimalloc inputs remain external and are hash-pinned, not copied into the promoted source tree.
