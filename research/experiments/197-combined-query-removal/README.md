## Hypothesis and change

The combined path removes only measured repeat work: 192's guarded previous/next vocab queries; 193's exact same-key miss lookup after a known prefill miss; and the temporary joined `word|` key allocation/copy used by the prefill lookup, replaced by 191's segmented trie walk. It retains ordered state-feature slots, score multiplicity, per-address resets, fallback for invalid front identity/allocation/sentinel cases, and the unchanged full lookup when guards fail. No country/key-specific shortcuts or cross-address cache.

Required diagnostics: neighbor-frequency guard reuse and fallbacks, checked miss markers and scorer skips, segmented prefix/tail/byte counts, fallback query calls, allocations, weight rows/adds, and memory. The standalone parents already supply individual screens; only combined speed/output/thread/memory are measured on this candidate.
